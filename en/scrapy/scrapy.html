03. AutoThrottle Engine & Diagnostic Matrix
Adaptive AutoThrottle Algorithm Dynamic Backoff
Adjusts download delay dynamically according to target server latency and response times.
1. Latency Calculation: Measures round-trip time (RTT) for each HTTP response.
2. Concurrency Target: Maintains AUTOTHROTTLE_TARGET_CONCURRENCY.
3. Proportional Delay: delay = latency / target_concurrency.
4. Safety Bounds: Clamped within START_DELAY and MAX_DELAY.
5. Backoff on Overload: Auto-throttles up upon receiving 503 or 429 status codes.
Failure Remediation Diagnostics
Cloudflare 403 Use residential proxies, modern Sec-CH headers, or Playwright sidecar.
Reactor Error Call asyncioreactor.install() prior to importing reactor.
OOM / Memory Balloon Set DEPTH_PRIORITY = 1 and enforce MEMUSAGE_LIMIT_MB.
DNS Timeouts Enable DNSCACHE_ENABLED = True and reduce DOWNLOAD_TIMEOUT.
04. Hardened Production Configuration (settings.py)
# ==============================================================================
# PhTex High-Performance Production Scrapy settings.py
# ==============================================================================
TWISTED_REACTOR = "twisted.internet.asyncioreactor.AsyncioSelectorReactor"
CONCURRENT_REQUESTS = 32                           # Max concurrent asynchronous I/O loops
CONCURRENT_REQUESTS_PER_DOMAIN = 16
DOWNLOAD_TIMEOUT = 15                              # Prevent hung socket resource starvation

# Adaptive AutoThrottle Rate Control
AUTOTHROTTLE_ENABLED = True
AUTOTHROTTLE_START_DELAY = 1.0
AUTOTHROTTLE_MAX_DELAY = 10.0
AUTOTHROTTLE_TARGET_CONCURRENCY = 2.0

# Retry Resiliency & Memory Protection
RETRY_ENABLED = True
RETRY_TIMES = 3
RETRY_HTTP_CODES = [500, 502, 503, 504, 522, 524, 408, 429]
MEMUSAGE_ENABLED = True
MEMUSAGE_LIMIT_MB = 2048                           # Terminate cleanly before OS OOM killer

# DNS Resolution Caching & Deduplication
DNSCACHE_ENABLED = True
DNSCACHE_SIZE = 10000
REQUEST_FINGERPRINTER_IMPLEMENTATION = "2.7"
DUPEFILTER_CLASS = "scrapy.dupefilters.RFPDupeFilter"

DEFAULT_REQUEST_HEADERS = {
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "en-US,en;q=0.9",
    "Upgrade-Insecure-Requests": "1",
}
