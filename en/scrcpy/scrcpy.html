03. Production Wireless Pipeline & Diagnostic Matrix
Low-Latency Wireless Profile TCP/IP 5555
High-performance configuration bypassing USB while maintaining 60 FPS and UHID input.
1. Pairing / Connect: adb connect 192.168.1.X:5555
2. Video Encoding: --video-codec=h265 -m 1600 -b 6M --max-fps=60
3. Audio Transport: --audio-codec=opus --audio-bit-rate=96K
4. Thermal Protection: --turn-screen-off --stay-awake
5. Input Fidelity: --keyboard=uhid --mouse=uhid
Failure Remediation Diagnostics
device unauthorized Check device screen; accept RSA authorization prompt.
MediaCodec Error Downgrade codec: --video-codec=h264 or cap -m 1080.
Wi-Fi Stutter / Lag Enforce 5GHz Wi-Fi; clamp -b 4M --max-fps=60 -m 1280.
No Audio Output Device runs Android < 11; pass --no-audio.
04. Production Automation Script (scrcpy-wireless.sh)
#!/usr/bin/env bash
# ==============================================================================
# PhTex High-Performance scrcpy Production Wireless Script
# ==============================================================================
DEVICE_IP="${1:-192.168.1.150}"

adb connect "${DEVICE_IP}:5555" || { echo "ADB connect failed"; exit 1; }

exec scrcpy \
  --tcpip="${DEVICE_IP}:5555" \
  --video-codec=h265 \
  --max-size=1600 \
  --video-bit-rate=6M \
  --max-fps=60 \
  --audio-codec=opus \
  --audio-bit-rate=96K \
  --turn-screen-off \
  --stay-awake \
  --keyboard=uhid \
  --mouse=uhid \
  --shortcut-mod=lalt \
  --window-title="Android [${DEVICE_IP}]"
