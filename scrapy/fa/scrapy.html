۰۲. گرامر دستورات و جدول ماتریس CLI
دستورات قلمرو پروژه محیط کاری
دستور مثال دستوری عملکرد سیستمی
crawl scrapy crawl sp -O out.jsonl اجرای اسپایدر و استریم به فایل خروجی.
parse scrapy parse --spider=sp <url> تست واحد کالبک‌های اسپایدر به طور مجزا.
genspider scrapy genspider -t crawl name site.com تولید قالب اولیه اسپایدر از روی الگو.
check scrapy check <spider_name> بررسی اعتبارسنجی قراردادها (Contracts).
دستورات سراسری سیستم مستقل
دستور مثال دستوری عملکرد سیستمی
shell scrapy shell "<url>" --nolog محیط تعاملی REPL برای ارزیابی سلکتورها.
fetch scrapy fetch --headers "<url>" دریافت سند خام HTTP با دانلودر داخلی.
view scrapy view "<url>" بررسی رندر صفحه در مرورگر برای تست JS.
runspider scrapy runspider single_spider.py اجرای مستقیم فایل پایتون بدون پروژه.
موتور انتخاب‌گرها: مقایسه CSS3 و XPath 1.0 مبتنی بر lxml در C
هدف استخراج ساختار نحو CSS3 معادل استاندارد XPath 1.0 مزیت و نکات فنی
مقدار ویژگی (Attribute) a::attr(href) //a/@href پشتیبانی XPath از توابع contains() و starts-with().
استخراج متن گره div.title::text //div[@class='title']/text() تجمیع بازگشتی متون نودهای فرزند با string(//div).
پیمایش معکوس والد غیرقابل پشتیبانی //input[@id='x']/ancestor::form پیمایش دوطرفه در کل گراف DOM بدون وابستگی به درخت.
استخراج با ریجکس css('h1::text').re(r'\d+') xpath('//h1/text()').re_first(r'\d+') تطبیق مستقیم الگو بدون تخصیص حافظه اضافه در پایتون.
۰۳. موتور کنترل تطبیقی AutoThrottle و جدول عیب‌یابی
منطق الگوریتم AutoThrottle تنظیم خودکار تأخیر
میزان تأخیر دانلود را به طور پویا بر اساس تأخیر پاسخ‌دهی (Latency) سرور مقصد تنظیم می‌کند.
۱. محاسبه تأخیر: محاسبه زمان رفت و برگشت (RTT) هر پاسخ HTTP.
۲. هدف‌گذاری هم‌روندی: حفظ ضریب AUTOTHROTTLE_TARGET_CONCURRENCY.
۳. فرمول تأخیر: delay = latency / target_concurrency.
۴. بازه امنیتی: محدودسازی بین مقادیر START_DELAY و MAX_DELAY.
۵. واکنش به ترافیک بالا: افزایش آنی تأخیر در صورت دریافت کدهای 503 یا 429.
جدول عیب‌یابی و سناریوهای بحرانی عیب‌یابی
خطای 403 کلودفلر استفاده از پروکسی مسکونی، هدرهای Sec-CH یا درایور Playwright.
خطای Reactor فراخوانی asyncioreactor.install() قبل از ایمپورت راکتور.
نشت رم و خطای OOM تنظیم DEPTH_PRIORITY = 1 و فعال‌سازی MEMUSAGE_LIMIT_MB.
تایم‌اوت DNS فعال‌سازی DNSCACHE_ENABLED = True و کاهش DOWNLOAD_TIMEOUT.
۰۴. فایل تنظیمات بهینه‌شده برای محیط عملیاتی (settings.py)
# ==============================================================================
# PhTex High-Performance Production Scrapy settings.py
# ==============================================================================
TWISTED_REACTOR = "twisted.internet.asyncioreactor.AsyncioSelectorReactor"
CONCURRENT_REQUESTS = 32                           # حداکثر چرخه‌های هم‌روند شبکه در حلقه رخداد
CONCURRENT_REQUESTS_PER_DOMAIN = 16
DOWNLOAD_TIMEOUT = 15                              # پیشگیری از قفل شدن پورت‌های معلق شبکه

# کنترل تطبیقی و هوشمند نرخ ارسال درخواست‌ها
AUTOTHROTTLE_ENABLED = True
AUTOTHROTTLE_START_DELAY = 1.0
AUTOTHROTTLE_MAX_DELAY = 10.0
AUTOTHROTTLE_TARGET_CONCURRENCY = 2.0

# تاب‌آوری در برابر خطاهای سرور و حفاظت از رم سرور
RETRY_ENABLED = True
RETRY_TIMES = 3
RETRY_HTTP_CODES = [500, 502, 503, 504, 522, 524, 408, 429]
MEMUSAGE_ENABLED = True
MEMUSAGE_LIMIT_MB = 2048                           # بستن ایمن پروسه قبل از فرخوانی OOM-killer سیستم عامل

# کش داخلی تفکیک آدرس DNS و فیلتر درخواست‌های تکراری
DNSCACHE_ENABLED = True
DNSCACHE_SIZE = 10000
REQUEST_FINGERPRINTER_IMPLEMENTATION = "2.7"
DUPEFILTER_CLASS = "scrapy.dupefilters.RFPDupeFilter"

DEFAULT_REQUEST_HEADERS = {
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "fa-IR,fa;q=0.9,en-US;q=0.8,en;q=0.7",
    "Upgrade-Insecure-Requests": "1",
}
