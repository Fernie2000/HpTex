۰۲. گرامر دستورات و پارامترهای خط فرمان (CLI)
انتقال داده و فشرده‌سازی تصویر ویدیو و شبکه
پارامتر پیش‌فرض عملکرد سیستمی
--tcpip=<ip:port> USB سوئیچ آنی به اتصال شبکه بی‌سیم.
-m, --max-size 0 (اصلی) کاهش رزولوشن تصویر (مانند 1080).
-b, --video-bit-rate 8M تنظیم سقف پهنای باند ویدیویی.
--max-fps 0 محدودسازی نرخ فریم (مانند 60 یا 30).
--video-codec h264 انتخاب کدک سخت‌افزاری: h264، h265، av1.
وضعیت دستگاه و ورودی‌ها کنترل سخت‌افزار
پارامتر پیش‌فرض عملکرد سیستمی
-S, --turn-screen-off false خاموش کردن صفحه فیزیکی گوشی.
-w, --stay-awake false ایجاد قفل بیداری (Wakelock) پردازنده.
--keyboard=<mode> sdk درایور ورودی: sdk، uhid، یا aoa.
--no-audio false غیرفعال‌سازی صوت (برای اندروید < ۱۱).
--record=out.mp4 none ضبط و استریم مستقیم به فایل ویدیویی.
کلیدهای میانبر درون‌برنامه‌ای (کلید پیش‌فرض MOD = Alt) کنترل بلادرنگ
کلید میانبر عملکرد سیستمی سیگنال ارسالی به اندروید
MOD + f تمام‌صفحه (Fullscreen) تغییر اندازه پنجره بین حالت شناور و تمام‌صفحه.
MOD + h / b / s خانه / بازگشت / برنامه‌های اخیر ارسال کدهای KEYCODE_HOME یا BACK یا منوی Recents.
MOD + p / o پاور / سیاه کردن صفحه فیزیکی خاموش/روشن کردن گوشی یا قطع نور پس‌زمینه پنل.
MOD + c / v همگام‌سازی کلیپ‌بورد انتقال متن بین کامپیوتر و حافظه کلیپ‌بورد گوشی.
MOD + Shift + v تزریق فیزیکی کاراکترها تبدیل متن به رویدادهای فشردن کیبورد سخت‌افزاری.
کشیدن و رها کردن فایل / APK نصب برنامه یا کپی فایل اجرای مستقیم adb install یا ذخیره در پوشه Download.
۰۳. پروفایل اتصال بی‌سیم و جدول خطایابی
پروفایل اتصال وای‌فای با تاخیر ناچیز پورت ۵۵۵۵
پیکربندی بهینه برای اتصال پایدار ۶۰ فریم بدون کابل با تایپ کیبورد فیزیکی.
۱. برقراری اتصال: adb connect 192.168.1.X:5555
۲. انکودر ویدیویی: --video-codec=h265 -m 1600 -b 6M --max-fps=60
۳. انتقال صدا: --audio-codec=opus --audio-bit-rate=96K
۴. مدیریت گرما: --turn-screen-off --stay-awake
۵. درایور کیبورد و ماوس: --keyboard=uhid --mouse=uhid
جدول رفع اشکال و سناریوهای بحرانی عیب‌یابی
خطای عدم دسترسی (unauthorized) باز کردن قفل گوشی و تایید کلید RSA در پاپ‌آپ USB.
خطای انکودر MediaCodec تنزل به H.264 با --video-codec=h264 یا محدودسازی به ۱۰۸۰.
فریز یا لگ تصویر در Wi-Fi استفاده از وای‌فای 5GHz و محدود کردن بیت‌ریت با -b 4M.
عدم انتقال صدای گوشی اندروید کمتر از ۱۱ است؛ سوئیچ --no-audio را لحاظ کنید.
۰۴. اسکریپت اتوماسیون اتصال بی‌سیم (scrcpy-wireless.sh)
#!/usr/bin/env bash
# ==============================================================================
# اسکریپت اختصاصی اتصال بی‌سیم با حداقل تاخیر در مجموعه PhTex
# ==============================================================================
DEVICE_IP="${1:-192.168.1.150}"

adb connect "${DEVICE_IP}:5555" || { echo "اتصال به دستگاه ناموفق بود"; exit 1; }

exec scrcpy \
  --tcpip="${DEVICE_IP}:5555" \
  --video-codec=h265 \
  --max-size=1600 \
  --video-bit-rate=6M \
  --max-fps=60 \
  --audio-codec=opus \
  --audio-bit-rate=96K \
  --turn-screen-off \
  --stay-awake \
  --keyboard=uhid \
  --mouse=uhid \
  --shortcut-mod=lalt \
  --window-title="گوشی اندروید [${DEVICE_IP}]"
