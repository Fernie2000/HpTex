tmux // ترمینال مالتی‌پلکسر، اتوماسیون و بازیابی سرور

تقسیم پنل‌ها، سوییچ بین تب‌ها، استخراج بافر لاگ‌ها، اسکریپت‌نویسی خودکار و بازیابی پس از ریبوت (tmux-resurrect)
۰۱. بنیاد عملکرد: تقسیم صفحه و پایپلاین کلید پیشوند (Ctrl+b)
تقسیم و جابجایی پنل‌ها (Panes) کادرها
عملکرد کلید ترکیبی
نصف کردن صفحه چپ و راست Ctrl+b سپس کلید %
نصف کردن صفحه بالا و پایین Ctrl+b سپس کلید "
حرکت مکان‌نما بین کادرها Ctrl+b سپس کلیدهای فلش
بزرگ‌نمایی موقت یک پنل (Zoom) Ctrl+b سپس حرف z
خروج موقت و امن (Detach) Ctrl+b سپس حرف d
اتصال مجدد در ترمینال اصلی دستور tmux attach
مدیریت چند پنجره (Windows / Tabs) تب‌ها
عملکرد در سشن کلید میانبر
ساخت پنجره مستقل جدید Ctrl+b سپس c
جابجایی به پنجره بعدی Ctrl+b سپس n
جابجایی به پنجره قبلی Ctrl+b سپس p
پرش به تب با شماره مشخص Ctrl+b سپس عدد 0 تا 9
تغییر نام پنجره فعلی (مثلاً logs) Ctrl+b سپس , (کاما)
مشاهده لیست تعاملی پنجره‌ها Ctrl+b سپس w
۰۲. لاگ‌گیری و پایپ خروجی کانتینر / اسکریپت
اگر پردازه‌ای با خروجی پیوسته و حجیم دارید و می‌خواهید خروجی‌های قدیمی بافر ترمینال یا پردازه جاری را ذخیره کنید:
۱. استخراج و ذخیره بافر اسکرول در فایل Buffer Dump

برای کشیدن ۳,۰۰۰ خط آخر لاگ‌های ترمینال به درون فایل متنی: 

tmux capture-pane -pS -3000 > ~/tmux_buffer.log

✓ کل متن‌های پیشین حتی متن‌های رد شده از کادر بدون نیاز به ماوس ذخیره می‌شوند.

۲. پایپ بلادرنگ به فایل با دستور tee Realtime Pipe

نمایش زنده روی مانیتور هم‌زمان با آپند شدن در لاگ فایل: 

python3 bot.py 2>&1 | tee -a bot.log

✓ هدایت استریم خطاها (stderr) و استاندارد (stdout) به صورت هم‌زمان.

۰۳. اسکریپت‌نویسی خودکار tmux (اجرا و بالا آوردن سرویس بدون تایپ دستی)
این اسکریپت Bash هنگام استارت سیستم چک می‌کند اگر سشن وجود نداشت، آن را به صورت Headless در پس‌زمینه (-d) می‌سازد، به دایرکتوری مورد نظر می‌رود، دستورات را اجرا می‌کند و در صورت نیاز اتچ می‌شود:
اسکریپت کامل اتوماسیون (startup_tmux.sh) Bash Daemon Automation 
#!/bin/bash
SESSION="production"

tmux has-session -t $SESSION 2>/dev/null

if [ $? != 0 ]; then
  # ساخت سشن دیمن در پس‌زمینه (-d)
  tmux new-session -d -s $SESSION -n "main"
  
  # ارسال دستورات مستقیم به سشن (C-m معادل کلید Enter است)
  tmux send-keys -t $SESSION:main "cd /root/app" C-m
  tmux send-keys -t $SESSION:main "railway shell" C-m
fi

# اتصال مستقیم به سشن در صورت اجرای تعاملی
tmux attach-session -t $SESSION
۰۴. جلوگیری از پاک شدن سشن‌ها هنگام ریستارت سرور (tmux-resurrect)
نرم‌افزار tmux به صورت پیش‌فرض در RAM مقیم است و با ریبوت VPS پاک می‌شود. با ابزار TPM و پلاگین tmux-resurrect سشن‌ها به صورت دائمی روی دیسک ذخیره و بازیابی می‌شوند:
گام ۱ و ۲: نصب مدیر پلاگین و کانفیگ پیکربندی

کلون کردن مخزن TPM در لینوکس:

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

افزودن این خطوط به انتهای ~/.tmux.conf:

set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'

run '~/.tmux/plugins/tpm/tpm'
گام ۳: کلیدهای ذخیره و بازیابی پس از ریبوت عملیاتی
هدف عملیاتی کلید میانبر در سشن
نصب پلاگین‌ها Ctrl+b سپس Shift+i (حرف I بزرگ)
ذخیره دستی کل وضعیت روی دیسک Ctrl+b سپس Ctrl+s
بازیابی کل سشن‌ها پس از ریستارت Ctrl+b سپس Ctrl+r

* پس از ریستارت سرور، فقط tmux را باز کنید و کلید Ctrl+b و سپس Ctrl+r را بزنید تا تمام تب‌ها و پنل‌ها زنده شوند.
