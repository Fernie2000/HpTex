# راهنمای جامع و پیشرفته: `tmux` (از الفبای مقدماتی تا اتوماسیون و سرور)

> **برای کیست؟** چه برای اولین بار است که اسم ترمینال را می‌شنوید و می‌خواهید صفحه سیاه را نصف کنید، و چه مدیر سیستم و برنامه‌نویسی هستید که به دنبال اسکریپت‌نویسی خودکار، پایداری سشن‌ها پس از ریستارت سرور (tmux-resurrect) و لاگ‌گیری بافر هستید؛ این مرجع کامل‌ترین راهنمای عملیاتی شماست.

---

## ۱. قبل از هر چیز: این پنجره سیاه (ترمینال) چیست؟

کامپیوتر شما دو چهره دارد:
1. **چهره گرافیکی:** همین صفحه‌ای که همیشه می‌بینید؛ با ماوس روی آیکون‌ها کلیک می‌کنید، پنجره‌ها را می‌کشید و دکمه ضربدر قرمز را می‌زنید.
2. **چهره متنی (خط فرمان یا ترمینال):** یک پنجره کاملاً سیاه و خلوت که فقط یک خط‌تیره چشمک‌زن (`_`) داخل آن است. در این پنجره، ماوس کاری انجام نمی‌دهد؛ به جای کلیک کردن، دستورات را با حروف انگلیسی تایپ می‌کنید و دکمه بزرگ کیبورد یعنی **Enter** را فشار می‌دهید تا کامپیوتر آن کار را اجرا کند.

### چطور این پنجره سیاه را باز کنیم؟
* **در ویندوز:** دکمه پرچم ویندوز (پایین سمت چپ کیبورد) را یک بار فشار دهید. عبارت `cmd` یا `powershell` را تایپ کنید و دکمه **Enter** را بزنید.
* **در سرور لینوکس یا SSH:** به محض اتصال به سرور (با PuTTY یا SSH)، این پنجره سیاه روبه‌روی شماست.

---

## ۲. اصل داستان: tmux چیست و چه مشکلی را حل می‌کند؟

وقتی در پنجره سیاه کار می‌کنید، با دو دردسر بزرگ روبه‌رو می‌شوید:

### دردسر اول: قفل شدن صفحه با یک کار
اگر فرمانی بدهید که طول بکشد (مثلاً دانلود یک فایل بزرگ یا اجرای یک ربات پایتون)، صفحه سیاه قفل می‌شود و تا پایان کار نمی‌توانید هیچ کار دیگری بکنید!

### دردسر دوم: بسته شدن همه چیز با قطع اینترنت
اگر با اینترنت به سروری در خارج وصل باشید و برنامه‌ای را روشن بگذارید، به محض اینکه اینترنت خانه یک ثانیه قطع شود یا درب لپ‌تاپ را ببندید، **همه چیز متوقف و نابود می‌شود!**

### راه‌حل جادویی: tmux وارد می‌شود
`tmux` برنامه‌ای است که داخل همان پنجره سیاه اجرا می‌شود و دو کار اساسی می‌کند:
1. **تقسیم صفحه (تصویر در تصویر):** صفحه سیاه را به ۲، ۳ یا ۴ مستطیل تقسیم می‌کند تا هم‌زمان چند برنامه را کنار هم تماشا کنید.
2. **حیات پایدار در پس‌زمینه:** می‌توانید لپ‌تاپ را خاموش کنید و بخوابید؛ برنامه‌های داخل tmux روی کامپیوتر مقصد بدون وقفه به کارشان ادامه می‌دهند. فردا که برگردید، همه چیز سر جای قبلی خود نشسته است!

---

## ۳. نحوه ورود و کلید جادویی پیشوند (Prefix)

### روشن کردن tmux:
داخل پنجره سیاه، فقط این کلمه ۵ حرفی را با حروف کوچک بنویسید و **Enter** بزنید:
```bash
tmux
```
یک نوار باریک سبز رنگ در پایین صفحه ظاهر می‌شود که نشان‌دهنده اجرای موفق tmux است.

### کلید نگهبان (Prefix Key):
برای اینکه tmux بفهمد می‌خواهید به خودش فرمان تقسیم صفحه بدهید (نه اینکه متن تایپ کنید)، اول کلید پیشوند را می‌زنیم:
1. کلید **`Ctrl`** (پایین سمت چپ کیبورد) را نگه دارید.
2. یک بار کلید حرف **`b`** را بزنید.
3. **هر دو دست را از کیبورد بردارید!**
4. حالا کلید دستور بعدی را فشار دهید.

---

## ۴. تقسیم صفحه به چند تکه (Panes)

* **نصف کردن عمودی (چپ و راست):** `Ctrl + b` دست بردارید، بعد `Shift + 5` (علامت `%`).
* **نصف کردن افقی (بالا و پایین):** `Ctrl + b` دست بردارید، بعد `Shift + '` (علامت `"`).
* **پریدن به مستطیل بغلی:** `Ctrl + b` دست بردارید، سپس دکمه‌های جهت کیبورد (فلش‌های چپ/راست/بالا/پایین).
* **بزرگ‌نمایی موقت یک کادر (Zoom):** `Ctrl + b` سپس کلید `z`. (برای برگشت دوباره همان را بزنید).
* **بستن یک کادر:** `Ctrl + b` سپس کلید `x` و سپس زدن کلید `y` جهت تایید.

---

## ۵. رفتن بدون قطع شدن کارها و بازگشت دوباره (Detach & Attach)

* **خروج ایمن و روشن ماندن برنامه‌ها (Detach):**  
  کلید `Ctrl + b` را بزنید، دست بردارید، سپس حرف **`d`** را بزنید. پیام `[detached]` می‌آید و می‌توانید پنجره را ببندید یا سرور را ترک کنید.
* **بازگشت به همان برنامه‌ها در روز بعد (Attach):**  
  پنجره سیاه را باز کنید و بنویسید:
  ```bash
  tmux attach
  ```
  و دکمه Enter را بزنید. همه چیز دقیقاً سر جای خود بازگردانده می‌شود!

---

## ۶. مدیریت چند پنجره (Windows / Tabs)

به جای اینکه برای هر کار یک سشن جدا بسازید، داخل یک سشن چندین پنجره مجزا (دقیقاً مانند تب‌های مرورگر اینترنت) باز کنید:

| دستور کلیدی | عملکرد در محیط کاربری |
| :--- | :--- |
| <kbd>Ctrl + b</kbd> سپس <kbd>c</kbd> | **ساخت پنجره جدید (Create):** یک صفحه سفید و مستقل ایجاد می‌کند. |
| <kbd>Ctrl + b</kbd> سپس <kbd>n</kbd> | **رفتن به پنجره بعدی (Next)** |
| <kbd>Ctrl + b</kbd> سپس <kbd>p</kbd> | **رفتن به پنجره قبلی (Previous)** |
| <kbd>Ctrl + b</kbd> سپس عدد (مثلاً <kbd>0</kbd> یا <kbd>1</kbd>) | **پرش مستقیم به تب شماره مشخص** |
| <kbd>Ctrl + b</kbd> سپس <kbd>,</kbd> (کاما) | **تغییر نام پنجره فعلی:** پنجره را به اسامی مثل `logs` یا `bot` تغییر نام دهید. |
| <kbd>Ctrl + b</kbd> سپس <kbd>w</kbd> | **مشاهده لیست تعاملی و ویژوال تمام پنجره‌ها و انتخاب با اینتر** |
| <kbd>Ctrl + b</kbd> سپس <kbd>&</kbd> | **بستن کامل پنجره جاری** (سپس زدن `y` برای تایید) |

---

## ۷. لاگ‌گیری و پایپ خروجی کانتینر / اسکریپت

اگر پروسه‌ای (مثل ربات، سرور نود یا کانتینر داکر) داری که خروجی‌های حجیم تولید می‌کند و می‌خواهی هم‌زمان متن آن در فایل ذخیره شود:

### ۱. ذخیره کل بافر اسکرول ترمینال در فایل متنی:
برای کشیدن متن‌های قدیمی ترمینال که به بالا اسکرول شده‌اند به داخل یک فایل متنی، این دستور را اجرا کنید:
```bash
tmux capture-pane -pS -3000 > ~/tmux_buffer.log
```
*(این دستور ۳,۰۰۰ خط اخیر بافر اسکرول را مستقیماً در فایل `tmux_buffer.log` ذخیره می‌کند).*

### ۲. پایپ خودکار خروجی ترمینال به فایل با ابزار `tee`:
برای اینکه خروجی استاندارد و خطاهای اسکریپت هم‌زمان روی مانیتور نمایش داده شده و داخل فایل لاگ هم ثبت شوند:
```bash
python3 bot.py 2>&1 | tee -a bot.log
```

## ۸. اسکریپت‌نویسی خودکار tmux (اتوماسیون سرور بدون دخالت دست)

می‌توانید اسکریپت Bash بسازید تا هنگام روشن شدن سرور، سشن را در پس‌زمینه ایجاد کند، وارد دایرکتوری پروژه شود و سرویس‌ها را اجرا کند بدون اینکه نیاز به تایپ دستی باشد:

```bash
#!/bin/bash
SESSION="production"

# بررسی وجود سشن از قبل
tmux has-session -t $SESSION 2>/dev/null

if [ $? != 0 ]; then
  # ساخت سشن در پس‌زمینه (-d) با نام main
  tmux new-session -d -s $SESSION -n "main"
  
  # ارسال دستورات مستقیم به سشن
  tmux send-keys -t $SESSION:main "cd /root/app" C-m
  tmux send-keys -t $SESSION:main "railway shell" C-m
fi

# اتصال به سشن در صورت اجرای تعاملی
tmux attach-session -t $SESSION
```

> [!NOTE]
> در دستور `send-keys`، عبارت **`C-m`** مخفف `Control + m` و معادل زدن فیزیکی کلید **Enter** است.

## ۹. جلوگیری از پاک شدن سشن‌ها هنگام ریستارت سرور (tmux-resurrect)

نرم‌افزار tmux به صورت پیش‌فرض در حافظه موقت (RAM) قرار دارد و با ریبوت شدن یا خاموش/روشن شدن VPS ریست می‌شود. برای ذخیره و بازیابی دائمی وضعیت تمام سشن‌ها و پنجره‌ها از پلاگین رسمی **`tmux-resurrect`** استفاده می‌کنیم:

### گام ۱: نصب ابزار TPM (Tmux Plugin Manager)
در خط فرمان لینوکس دستور زیر را اجرا کنید:
```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

### گام ۲: ویرایش فایل تنظیمات `~/.tmux.conf`
این خطوط را در انتهای فایل `~/.tmux.conf` قرار دهید:
```tmux
set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-resurrect'

# بارگذاری هسته TPM (همیشه باید در آخرین خط فایل باشد)
run '~/.tmux/plugins/tpm/tpm'
```

سپس دستور زیر را در ترمینال بزنید تا تنظیمات بارگذاری شود:
```bash
tmux source ~/.tmux.conf
```

### گام ۳: کلیدهای میانبر ذخیره و بازیابی سشن‌ها
داخل محیط tmux:
* **نصب پلاگین‌های جدید:** کلید <kbd>Ctrl + b</kbd> سپس کلید <kbd>Shift + i</kbd> (حرف `I` بزرگ انگلیسی). پیامی مبنی بر نصب موفق ظاهر می‌شود.
* **ذخیره دستی وضعیت تمام سشن‌ها، پنجره‌ها و پنل‌ها روی دیسک:**  
  کلید <kbd>Ctrl + b</kbd> سپس هم‌زمان کلیدهای <kbd>Ctrl + s</kbd>.
* **بازیابی کامل سشن‌ها پس از ریبوت سرور:**  
  کلید <kbd>Ctrl + b</kbd> سپس هم‌زمان کلیدهای <kbd>Ctrl + r</kbd>. در چند ثانیه تمام پنجره‌های قبلی زنده می‌شوند!
