03. The Vi Buffer Engine & Clipboard Pipeline
Vi Copy Mode Pipeline Memory Buffer
Scrollback is stored in server-allocated memory, isolated from terminal viewport limitations.
1. Enter Mode: Prefix [
2. Vi Navigation: h j k l, Ctrl+u, Ctrl+d
3. Search: / (forward), ? (backward)
4. Visual Select: v
5. Yank (Copy): y ➔ passes to OS clipboard & buffer
6. Paste Buffer: Prefix ]
Failure Remediation Diagnostics
Vim Esc Delay Set escape-time 0 in config to remove modal delay.
Color Loss Enforce default-terminal "tmux-256color" + RGB overrides.
Nested SSH Press Prefix twice to pass hotkey to guest session.
Small Viewport Enable setw -g aggressive-resize on.
04. Hardened Production Configuration (~/.tmux.conf)
# ==============================================================================
# PhTex High-Performance Production .tmux.conf
# ==============================================================================
unbind C-b
set -g prefix C-a                                  # Ergonomic prefix mapping
bind C-a send-prefix

set -g default-terminal "tmux-256color"            # Full 24-bit Truecolor RGB
set -ag terminal-overrides ",xterm-256color:RGB"
set -s escape-time 0                               # 0ms delay for Neovim/Vim
set -g history-limit 50000                         # 50,000 line scrollback buffer
set -g mouse on                                    # Full mouse support

set -g base-index 1                                # 1-based indexing for windows & panes
setw -g pane-base-index 1
set -g renumber-windows on

# Intuitive Split & Directory Preservation
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# Vi Navigation Chords
bind h select-pane -L \; bind j select-pane -D \; bind k select-pane -U \; bind l select-pane -R
setw -g mode-keys vi
bind -T copy-mode-vi v send-keys -X begin-selection
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "wl-copy || xclip -in -selection clipboard"

# Minimalist Status Bar Design
set -g status-style "bg=#1e1e2e,fg=#cdd6f4"
set -g status-left "#[bg=#89b4fa,fg=#11111b,bold]  #S #[bg=#1e1e2e,fg=#89b4fa] "
set -g window-status-current-format "#[fg=#11111b,bg=#a6e3a1,bold] #I:#W "
bind r source-file ~/.tmux.conf \; display-message "Config Reloaded."
