# مشخصات فنی و راهنمای جامع عملیاتی: `scrcpy` (Screen Copy)

> **رده سند:** مرجع استاندارد مهندسی سیستم  
> **حوزه تخصصی:** مجازی‌سازی و انتقال تصویر با تاخیر ناچیز، تعامل سطح پایین با زیرسیستم اندروید، تونلینگ ADB  
> **نسخه هدف:** `scrcpy >= 2.4` / سیستم‌عامل `Android >= 5.0` (قابلیت صوت: `Android >= 11`)

---

## ۱. آناتومی معماری و پایپ‌لاین داخلی سیستم

نرم‌افزار `scrcpy` امکان کنترل بلادرنگ و نمایش تصویر دستگاه‌های اندرویدی را با حداقل تاخیر ممکن بدون نیاز به دسترسی روت (Root) یا نصب هرگونه اپلیکیشن جانبی روی گوشی فراهم می‌سازد. این ابزار از طریق تزریق پویا و موقت یک سرور مبتنی بر جاوا (`scrcpy-server.jar`) در بستر پروتکل خطایابی اندروید (`adb`) عمل می‌کند.

```text
+-------------------------------------------------------------------------+
|                              سیستم میزبان (Host)                         |
|                                                                         |
|  [ رندرر گرافیکی SDL2 ] <=== فریم‌های خام === [ دیکودر سخت‌افزاری FFmpeg ]|
|         ▲                                                 ▲             |
|         |                                                 |             |
|  [ رویدادهای ورودی کیبورد و ماوس ]                  [ دیمالتی‌پلکسر / پارسر ] |
|         |                                                 ▲             |
|         ▼                                                 |             |
|  [ کنترلر scrcpy ] ───── بسته‌های کنترلی ─────> [ سوکت تونل ADB ]        |
+-----------------------------------------------------------│-------------+
                                                            │ کابل USB یا شبکه بی‌سیم TCP (5555)
+-----------------------------------------------------------│-------------+
|                            دستگاه اندرویدی (Target)       ▼             |
|                                                  [ دیمن adbd ]          |
|                                                           │             |
|  +────────────────────────────────────────────────────────┼──────────+  |
|  │ سرور موقت جاوا (اجرا با app_process در مسیر /data/local/tmp)       │  |
|  │                                                                   │  |
|  │  [ لایه گرافیکی SurfaceControl / DisplayManager ]                 │  |
|  │                         │ (بافر سرفیس)                            │  |
|  │                         ▼                                         │  |
|  │  [ انکودر سخت‌افزاری MediaCodec ] ──> استریم ویدیویی H.264 / H.265 │  |
|  │                                                                   │  |
|  │  [ کپچر استریم صوت AudioPlaybackCapture ] ──> صدای فشرده Opus/AAC  │  |
|  │                                                                   │  |
|  │  [ درایور سخت‌افزاری کرنل InputManager / UHID ] <── تزریق ورودی‌ها   │  |
|  +───────────────────────────────────────────────────────────────────+  |
+-------------------------------------------------------------------------+
```

### اجزای اصلی سازوکار زیرسیستم

۱. **فرآیند راه‌اندازی (Bootstrap):** کلاینت فایل `scrcpy-server.jar` را از طریق دستور `adb push` درون مسیر موقت حافظه رم دستگاه (`/data/local/tmp`) بارگذاری کرده و آن را با دستور سیستمی `app_process` تحت دسترسی کاربری شل اندروید (`UID 2000`) بالا می‌آورد.  
۲. **کپچر و کدگذاری ویدیو:** سرور با فراخوانی مستقیم APIهای خصوصی `SurfaceControl`، تصویر صفحه را بدون واسطه در حافظه به ماژول پردازش سخت‌افزاری `MediaCodec` در تراشه چیپست (SoC) هدایت می‌کند.  
۳. **لایه انتقال داده:** واحدهای کدگذاری‌شده NAL (فرمت H.264، H.265 یا AV1) و جریان صوتی فشرده‌شده از طریق پورت فوروارد رمزنگاری‌شده محلی به کلاینت مخابره می‌شوند.  
۴. **دیکود و رندر گرافیکی:** کلاینت میزبان با استفاده از شتاب‌دهنده گرافیکی کارت گرافیک سیستم میزبان (NVDEC، VAAPI یا DXVA2) فریم‌ها را باز کرده و در بستر بافت‌های GPU کتابخانه SDL2 با تاخیر استثنایی **۳۵ الی ۷۰ میلی‌ثانیه** ترسیم می‌کند.  
۵. **پروتکل‌های تزریق ورودی:**
   * **حالت `sdk` (پیش‌فرض):** ارسال رویدادهای لمسی و کلیدها از طریق فراخوانی متدهای داخلی کلاس `InputManager`.
   * **حالت‌های سخت‌افزاری `uhid` و `aoa`:** شبیه‌سازی درگاه واقعی ماوس و کیبورد USB در سطح کرنل لینوکس گوشی (حذف کامل باگ‌های تایپ فارسی و محدودیت‌های نرم‌افزاری صفحه‌کلید).

## ۲. گرامر دستورات و پارامترهای خط فرمان (CLI)

تمام عملیات اجرایی از طریق باینری `scrcpy` و سوئیچ‌های ساختاریافته کنترل می‌شوند:

| فلگ / پارامتر | مقدار پیش‌فرض | عملکرد فنی و سیستمی |
| :--- | :--- | :--- |
| **`-s, --serial=<serial>`** | اولین دستگاه | انتخاب یک دستگاه خاص در صورت اتصال هم‌زمان چند گوشی به ADB. |
| **`--tcpip[=<ip:port>]`** | حالت خودکار | قطع وابستگی به کابل USB و سوئیچ ارتباط به شبکه بی‌سیم Wi-Fi. |
| **`-m, --max-size=<val>`** | `0` (ابعاد اصلی) | کاهش رزولوشن تصویر به ابعاد مشخص (مانند `1080` یا `1440`) با حفظ نسبت تصویر. |
| **`-b, --video-bit-rate=<val>`** | `8M` | تعیین پهنای باند و بیت‌ریت استریم ویدیو (مانند `4M` یا `16M`). |
| **`--max-fps=<val>`** | بدون محدودیت | تعیین سقف نرخ فریم بر ثانیه (مانند `60` یا `30`) جهت کاهش مصرف باتری و دمای پردازنده. |
| **`--video-codec=<codec>`** | `h264` | انتخاب الگوریتم انکودر: `h264`، `h265` یا `av1` (بسته به پشتیبانی سخت‌افزاری گوشی). |
| **`--no-audio`** | `false` | غیرفعال‌سازی استریم صدا (الزامی برای دستگاه‌های دارای `Android < 11`). |
| **`-S, --turn-screen-off`** | `false` | خاموش کردن کامل پنل فیزیکی نمایشگر گوشی در حین حفظ و انتقال تصویر به کامپیوتر. |
| **`-w, --stay-awake`** | `false` | جلوگیری از رفتن دستگاه به حالت خواب عمیق (Sleep) با ایجاد قفل بیداری (Wakelock). |
| **`--record=<file.mp4>`** | بدون ضبط | ذخیره هم‌زمان استریم خام تصویر بدون انکود مجدد درون فایل‌های ویدیویی MP4 یا MKV. |
| **`--keyboard=<mode>`** | `sdk` | حالت کیبورد: `sdk`، `uhid` یا `aoa` (شبیه‌سازی فیزیکی صفحه‌کلید سخت‌افزاری USB). |
| **`--video-source=camera`** | `display` | تبدیل دوربین باکیفیت گوشی به وب‌کم مجازی کامپیوتر. |

## ۳. جدول کلیدهای میانبر درون‌برنامه‌ای

کلیدهای کنترلی بر پایه کلید ترکیبی **`MOD`** (که به صورت پیش‌فرض کلید `Alt` چپ روی ویندوز و لینوکس است) عمل می‌کنند:

| کلید میانبر | عملکرد سیستمی | نتیجه عملیاتی روی دستگاه |
| :--- | :--- | :--- |
| <kbd>MOD</kbd> + <kbd>f</kbd> | **تمام‌صفحه (Fullscreen)** | تغییر اندازه پنجره SDL بین حالت شناور و تمام‌صفحه بدون حاشیه. |
| <kbd>MOD</kbd> + <kbd>h</kbd> | **کلید خانه (Home)** | ارسال سیگنال کلید خانه (`KEYCODE_HOME`) به مدیریت پنجره اندروید. |
| <kbd>MOD</kbd> + <kbd>b</kbd> | **کلید بازگشت (Back)** | ارسال سیگنال بازگشت (`KEYCODE_BACK`) (کلیک راست ماوس نیز این عمل را انجام می‌دهد). |
| <kbd>MOD</kbd> + <kbd>s</kbd> | **برنامه‌های اخیر (Overview)** | باز کردن فهرست مالتی‌تسکینگ و اپلیکیشن‌های فعال اخیر. |
| <kbd>MOD</kbd> + <kbd>p</kbd> | **کلید پاور (Power)** | شبیه‌سازی فشردن دکمه فیزیکی پاور دستگاه (`KEYCODE_POWER`). |
| <kbd>MOD</kbd> + <kbd>o</kbd> | **سیاه کردن صفحه فیزیکی** | خاموش کردن نور صفحه نمایشگر فیزیکی بدون قطع استریم. |
| <kbd>MOD</kbd> + <kbd>جهت‌ها</kbd> | **تنظیم صدا (Volume)** | افزایش یا کاهش میزان خروجی صدای چندرسانه‌ای گوشی. |
| <kbd>MOD</kbd> + <kbd>n</kbd> / <kbd>Shift+n</kbd> | **پنل اعلان‌ها (Notifications)** | باز کردن یا بستن کشوی نوتیفیکیشن‌ها و تنظیمات سریع. |
| <kbd>MOD</kbd> + <kbd>c</kbd> | **کپی کلیپ‌بورد گوشی** | انتقال محتوای متنی حافظه موقت گوشی به کلیپ‌بورد سیستم کامپیوتر. |
| <kbd>MOD</kbd> + <kbd>v</kbd> | **الصاق به گوشی (Paste)** | تزریق مستقیم متن کلیپ‌بورد سیستم به فیلد متنی انتخاب‌شده در گوشی. |
| <kbd>MOD</kbd> + <kbd>Shift+v</kbd> | **تزریق مستقیم کاراکترها** | تبدیل رشته متنی به رویدادهای فشردن دکمه کیبورد برای دور زدن محدودیت‌های امنیتی. |
| **کشیدن و رها کردن APK** | **نصب فوری برنامه** | اجرای آنی دستور استریمینگ `adb install -r <file.apk>`. |
| **کشیدن و رها کردن فایل** | **انتقال به حافظه داخلی** | کپی سریع فایل‌ها به مسیر دایرکتوری `/sdcard/Download/`. |

## ۴. پروفایل‌های اجرایی بهینه‌شده و اسکریپت‌های اتوماسیون

جهت کاهش تاخیر، کنترل مصرف شبکه بی‌سیم و استفاده از قابلیت‌های پیشرفته، از این اسکریپت‌ها استفاده کنید:

### پروفایل اتصال بی‌سیم با حداقل تاخیر (`scrcpy-wireless.sh`)

```bash
#!/usr/bin/env bash
# ==============================================================================
# پروفایل ارتباط وای‌فای با تاخیر ناچیز و کیبورد سخت‌افزاری UHID
# ==============================================================================
DEVICE_IP="${1:-192.168.1.150}"

echo "[*] برقراری اتصال بی‌سیم با سوکت شبکه..."
adb connect "${DEVICE_IP}:5555" || { echo "[!] خطا در اتصال ADB"; exit 1; }

exec scrcpy \
  --tcpip="${DEVICE_IP}:5555" \
  --video-codec=h265 \
  --max-size=1600 \
  --video-bit-rate=6M \
  --max-fps=60 \
  --audio-codec=opus \
  --audio-bit-rate=96K \
  --turn-screen-off \
  --stay-awake \
  --keyboard=uhid \
  --mouse=uhid \
  --shortcut-mod=lalt \
  --window-title="اندروید [${DEVICE_IP}]"
```

### تبدیل دوربین گوشی به وب‌کم حرفه‌ای کامپیوتر (`scrcpy-webcam.sh`)

```bash
#!/usr/bin/env bash
# استفاده از سنسور دوربین اصلی به عنوان وب‌کم مجازی فوق باکیفیت
exec scrcpy \
  --video-source=camera \
  --camera-facing=back \
  --camera-size=1920x1080 \
  --camera-fps=60 \
  --no-audio \
  --v4l2-sink=/dev/video2 \
  --stay-awake
```

## ۵. جدول عیب‌یابی و سناریوهای بحرانی

| نشانه و خطا | ریشه فنی مشکل | راه‌حل قطعی و مهندسی |
| :--- | :--- | :--- |
| **خطای `device unauthorized`** | کلید امنیتی RSA سیستم کامپیوتر روی صفحه گوشی تایید نشده است. | باز کردن قفل گوشی و تیک زدن گزینه "Always allow from this computer" در پاپ‌آپ USB. |
| **خطای انکودر `MediaCodec error`** | چیپست پردازنده توانایی پردازش رزولوشن یا فرمت کدک درخواستی را ندارد. | تنزل کدک به H.264 با `--video-codec=h264` یا محدودسازی اندازه با `--max-size=1080`. |
| **لگ شدید و فریز تصویر در Wi-Fi** | نوسان پینگ شبکه، تداخل امواج فرکانس 2.4GHz یا بیت‌ریت بیش از حد بالا. | اتصال به باند فرکانسی 5GHz و اعمال محدودیت پهنای باند: `--max-fps=60 -b 4M --max-size=1280`. |
| **تایپ نشدن حروف فارسی با کیبورد** | حالت پیش‌فرض `sdk` کدهای استاندارد اسکی ارسال می‌کند. | فعال‌سازی شبیه‌سازی درگاه فیزیکی با سوئیچ‌های `--keyboard=uhid` یا `--keyboard=aoa`. |
| **عدم انتقال صدا به سیستم** | نسخه سیستم‌عامل اندروید گوشی کمتر از ۱۱ است. | انتقال مستقیم صدا نیازمند اندروید ۱۱ به بالاست؛ در نسخه‌های قدیمی‌تر سوییچ `--no-audio` را اعمال کنید. |
