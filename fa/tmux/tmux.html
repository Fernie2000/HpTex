معماری جامع سیستمی، جبر ناوبری و کلیدهای میانبر، مدیریت بافرهای Vi و کانفیگ پایدار
۰۱. آناتومی معماری و توپولوژی سیستم
جداسازی کامل چرخه عمر کلاینت از پروسه‌های سرور
ابزار tmux در قالب یک دیمن پس‌زمینه ناهمگام (`tmuxd`) اجرا شده و کلیه پردازه‌های درون ترمینال را از چرخه عمر پنجره‌های گرافیکی یا نشست‌های ناپایدار SSH ایزوله می‌سازد.

۰۲. گرامر دستورات و جدول کلیدهای میانبر
مدیریت چرخه نشست‌ها (Sessions) عمومی
عملیات دستور خط فرمان (CLI) کلید تعاملی
ساخت نشست جدید tmux new -s <name> :new -s <name>
اتصال به نشست هدف tmux attach -t <name> —
خروج از نشست (Detach) tmux detach Prefix d
درخت تعاملی نشست‌ها tmux choose-tree -s Prefix s
تغییر نام نشست tmux rename-session <n> Prefix $
بستن کامل نشست tmux kill-session -t <n> :kill-session
مجازی‌سازی پنجره‌ها (Windows) تب‌ها
عملیات دستور خط فرمان کلید تعاملی
ساخت پنجره جدید tmux new-window -n <n> Prefix c
پنجره بعدی / قبلی tmux next-window / prev Prefix n / p
پرش مستقیم با شماره tmux select-window -t <i> Prefix 0..9
فهرست تعاملی پنجره‌ها tmux choose-tree -w Prefix w
تغییر نام پنجره جاری tmux rename-window <n> Prefix ,
بستن و نابودی پنجره tmux kill-window Prefix &
هندسه و تقسیم‌بندی پنل‌ها (Panes) ارگونومیک
عملیات کلید پیش‌فرض کلید بهینه‌شده (.tmux.conf) دستور سیستمی زیرین
تقسیم افقی (کنار هم / Split Horizontal) Prefix % Prefix | split-window -h -c "#{pane_current_path}"
تقسیم عمودی (زیر هم / Split Vertical) Prefix " Prefix - split-window -v -c "#{pane_current_path}"
ناوبری جهت‌دار بین پنل‌ها Prefix جهت‌ها Prefix h j k l select-pane -[U|D|L|R]
بزرگ‌نمایی موقت پنل (Zoom Toggle) Prefix z Prefix z resize-pane -Z (حفظ ساختار پنجره‌ها)
چرخش الگوهای چیدمان Prefix Space Prefix Space next-layout (افقی، عمودی، کاشی‌کاری)
همگام‌سازی ورودی تمام پنل‌ها :setw synchronize-panes Prefix y ارسال همزمان کلیدها به همه شل‌های فعال
۰۳. مدیریت بافرهای Vi و خط‌لوله کلیپ‌بورد
فرایند کپی و ناوبری بافر حافظه سرور
تاریخچه اسکرول درون حافظه اختصاصی سرور نگهداری شده و به محدودیت‌های ترمینال وابسته نیست.
۱. ورود به حالت اسکرول: Prefix [
۲. ناوبری مطابق Vim: h j k l و Ctrl+u / Ctrl+d
۳. جستجو در متن: / (رو به جلو) و ? (رو به عقب)
۴. شروع انتخاب متن: v
۵. رونوشت (کپی): y ➔ انتقال به کلیپ‌بورد سیستم و بافر داخلی
۶. الصاق (Paste): Prefix ]
جدول رفع اشکال و پیشگیری عیب‌یابی
تاخیر کلید Esc در Vim تنظیم escape-time 0 در فایل کانفیگ جهت حذف تاخیر.
به‌هم‌ریختگی رنگ‌ها اعمال default-terminal "tmux-256color" و RGB overrides.
نشست تودرتوی SSH فشردن دو بار کلید Prefix جهت ارسال به نشست مهمان.
محدودیت سایز کلاینت فعال‌سازی setw -g aggressive-resize on.
۰۴. فایل کانفیگ بهینه‌شده برای محیط عملیاتی (~/.tmux.conf)
# ==============================================================================
# PhTex High-Performance Production .tmux.conf (Light Theme Build)
# ==============================================================================
unbind C-b
set -g prefix C-a                                  # پیشوند ارگونومیک با کلید Ctrl-a
bind C-a send-prefix

set -g default-terminal "tmux-256color"            # پشتیبانی از رنگ‌های ۲۴ بیتی Truecolor
set -ag terminal-overrides ",xterm-256color:RGB"
set -s escape-time 0                               # تاخیر صفر ثانیه برای ادیتور Neovim/Vim
set -g history-limit 50000                         # ۵۰ هزار خط تاریخچه اسکرول
set -g mouse on                                    # فعال‌سازی کامل اشاره‌گر ماوس

set -g base-index 1                                # شماره‌گذاری پنجره‌ها و پنل‌ها از ۱
setw -g pane-base-index 1
set -g renumber-windows on

# کلیدهای بصری تقسیم پنجره و حفظ دایرکتوری جاری
bind | split-window -h -c "#{pane_current_path}"
bind - split-window -v -c "#{pane_current_path}"

# ناوبری سریع پنل‌ها با حروف Vim
bind h select-pane -L \; bind j select-pane -D \; bind k select-pane -U \; bind l select-pane -R
setw -g mode-keys vi
bind -T copy-mode-vi v send-keys -X begin-selection
bind -T copy-mode-vi y send-keys -X copy-pipe-and-cancel "wl-copy || xclip -in -selection clipboard"

# استایل نوار وضعیت مدرن و مینیمال
set -g status-style "bg=#e2e8f0,fg=#0f172a"
set -g status-left "#[bg=#4f46e5,fg=#ffffff,bold]  #S #[bg=#e2e8f0,fg=#4f46e5] "
set -g window-status-current-format "#[fg=#ffffff,bg=#059669,bold] #I:#W "
bind r source-file ~/.tmux.conf \; display-message "کانفیگ مجدداً بارگذاری شد."
